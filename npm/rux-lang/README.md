# rux-lang

Official npm distribution wrapper for the experimental RUX language interpreter.

After the matching GitHub Release has been published and this package has been published to npm:

```bash
npm install -g rux-lang
rux --version
rux run hello.rux
```

The installer downloads the binary for the current operating system from GitHub Releases and checks its SHA-256 digest before installation. Supported platforms: Windows x64, Linux x64, macOS arm64.

**Not published yet.** The package version must match a GitHub release tag, for example `0.1.0-alpha.1` -> `v0.1.0-alpha.1`.

Source: https://github.com/ebercamargo/rux
